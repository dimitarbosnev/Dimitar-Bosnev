What is Networking?

Networking is a course I took during the second year of my CMGT study. In this course I had to complete 3 assignments from which I was able to learn about game networking, the networking stack, how to program sockets and how to write application protocols.

C# Unity Network Programming

Assignment 1

During this assignment I had to create a chat lobby which included a server and a client and client interface. In this assignment I was able to learn how to send data over sockets and how to retrive that data from a stream.

Networking Assignment 1

Assignment 2

During this assignment I had to expand on the chat loby from the previous assignment and create a litte town which would have players being able to walk around and send message through their avatar. For this assignment I had to learn how to serialize and deserialize objects and send the over in packages in order to create a more rovust and scalable system.

Networking Assignment 2

Assignment 3

During this assignment I had to create a chat lobby using the package system from the previous assignment but also expand the server to use a room setup. Since players in this assignment could now queue for a game and then be brought back to the main chat lobby when finished.
