3D Rendering

Home Projects 3D Rendering

This project marks the beginning of my journey into graphics programming. It started as a university course where I learned the basics of rendering in 3D space using the OpenGL API. Working through a series of assignments, I gradually took on more complex topics like lighting models, mesh manipulation, and triplanar mapping.

What fascinated me most was seeing how much could be built from understanding the low-level details myself. That curiosity inspired me to keep going in this direction, which eventually led me to build my own engine from scratch—CMGT-Engine—now powered by the Vulkan API.

C++ OpenGL Graphics Programming Shader Programming

Assignment 1

The first assignment introduced me to fragment shaders, and more importantly, to how I could control them through shader uniforms. I created a shader that rendered a checkerboard pattern and applied a lighting effect that responded to my mouse position, giving the scene a basic sense of depth and direction.

3D Rendering assignment 1

Assignment 2

For this assignment I built a parent/child system inside the small game engine we were given for the course, and added a camera that orbits around a selected object. The most interesting part for me was having to work out the math myself—applying concepts I had already learned in a previous course and seeing how they fit together in practice.

3D Rendering Assignment 2

Assignment 3

In this assignment I implemented a multi-light model that combined directional lights, point lights, and Phong specular lighting. What I enjoyed most was the process itself—seeing the result update after each implementation step, which let me isolate how each light type contributed to the final scene.

3D Rendering Assignment 3

Assignment 4

The final assignment pushed me toward texture work. I created a vertex shader that extruded the vertices of a mesh based on a height map, paired with a fragment shader that blended textures using a splat map. What I found most interesting was seeing how textures could be used in much broader ways than simply shading a surface—they could actively reshape and define the geometry of what I was rendering.
